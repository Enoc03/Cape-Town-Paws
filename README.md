# Cape Town Paws Website

## Project Overview

Cape Town Paws is a non-profit animal rescue organisation based in Cape Town. The organisation focuses on rescuing, rehabilitating and rehoming abandoned, neglected and injured animals.

This website was created to give Cape Town Paws a professional and organised online presence. It allows users to learn more about the organisation, view its services, make enquiries and find contact information.

## Website Pages

The website includes the following pages:

- Home
- About Us
- Services
- Enquiry
- Contact

## Main Features

The website includes:

- Responsive navigation
- Cape Town Paws logo
- Hero section
- Animal rescue images
- Service cards
- Adoption, fostering and volunteering information
- Enquiry form
- Contact form
- Responsive desktop, tablet and mobile layouts
- CSS hover, focus and active effects
- Flexbox and CSS Grid layouts
- External CSS stylesheet

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

## Design

The website uses a soft blue, white and warm neutral colour scheme to create a calm, friendly and trustworthy appearance.

The design uses clear headings, readable text, visible buttons and consistent navigation to make the website easy to use.

## Responsive Design

The website has been designed to work on different screen sizes.

Media queries are used to adapt the layout for:

- Desktop computers
- Tablets
- Mobile phones

Layouts that display multiple columns on larger screens change to single-column layouts on smaller screens.
